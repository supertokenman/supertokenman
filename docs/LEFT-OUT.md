# What is left out, deferred or not verified

One place for what the roadmaps and phase reports said was not done. Update it with every phase.

## Left out on purpose

| What | Why |
|---|---|
| Running Open WebUI, textgen, PostHog, NocoDB, Cal.diy, Dify or Immich inside the app | Each is a full server with its own accounts and licenses; the app talks to the one you run. |
| Code from AGPL/GPL or restrictive projects (textgen, Postiz, Memoh, Immich, NocoDB, Dify, Open WebUI, Netdata UI) | Ideas only, or run as a separate program you install (trufflehog). |
| Enterprise folders (Langfuse, PostHog, Rocket.Chat `ee/`, Dokploy `/proprietary`) | Separate licenses. |
| sherlock | Searches sites for a username; builds a profile of a person. |
| hackingtool | Offensive tooling. Defensive scanning is phases 39 and 40. |
| Downloading videos or captions (yt-dlp) | Project rule; metadata only. |
| Live trading | Backtests and paper trading only. |
| Cloning live websites pixel for pixel | Owners' rights; no impersonation. |
| Agents always on that act alone, tools on the host by default, commands from chat DMs | Every action stays visible and approved. |
| Migrating keys out of other tools, full computer-use agent, automatic user profiles | Vault rule, safety, privacy. |
| Automatic cleanup or stopping of cloud resources | Never automatic. |
| Face recognition in the photo library | Biometric data. |

## Parked (maybe later)

- A harness adapter for other CLIs (Codex, OpenCode): high risk, large effort.
- None of the old parked phases are left (16, 25, 9, 18 and 10 are done: see below).

## Not verified against the real thing

Every phase was tested in Electron on Linux against fake servers, in both themes. Not checked:
- WebGL renderer: under xvfb there is no GPU, so the fallback renderer ran; the WebGL path itself was not seen on a Mac.

- The real Claude API and the Mac build (and the Mac tray, Skill() in disallowedTools).
- Real Ollama, mail and social APIs.
- Real vLLM, llama.cpp, LM Studio; vLLM started over SSH, the tunnel and the log.
- Real Langfuse; how spans look inside it.
- Real Netdata; TLS certificate expiry on a real site; system notifications (xvfb shows none).
- Real trivy and its database download (GitHub releases gave 403 here); image scans.
- Real trufflehog, live key verification, the pre-push hook blocking a real push.
- Real PostHog (API shapes, key scopes, large projects).
- Real Dokploy (`project.all`, `deployment.all`, `rollback.rollback` names are from its API as known, not confirmed).
- Real Prometheus with auth and heavy queries.
- The MCP catalog against GitHub itself (a local copy of the list and a fake repo host were used); a real MCP server started through `stm mcp-run` inside Claude Code.
- Real prompts.chat download (a local cut of the CSV was used).
- The V11 analysis could not read GitHub stars, last commits or archived status (403).
- `tsc` on the renderer reports one old error in `src/state.ts`; the build and the electron `tsc` pass.
