# Review checklist

Before you report a change as done, go through this list and say which items you checked.

1. Run the project's tests, or say why you could not.
2. Name one edge case the change does not cover, and say whether that is fine.
3. Search the diff for leftovers: debug output, commented-out code, TODOs you added.
4. Check that names in the diff say what the code does.
5. State what you did not touch on purpose.
