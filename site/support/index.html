Support

Free, and open source.

SuperTokenMan costs nothing and its code is public. If it saves you time, you can help keep it going.

Sponsor on GitHub Star on GitHub

What the money pays for

  • SigningThe Apple Developer Program, which lets macOS open the app without warnings.
  • AuditsSecurity checks on every release, and an outside review before anything is sold.
  • TimeFixes, new versions and answers to the issues you open.

What it never buys

  • AdsNo ads and no sponsored suggestions inside the app.
  • DataNo access to anything about the people who use it. The app has no telemetry to share.
  • SayNo say over what the Security page states. Company sponsors appear only as a logo on this site and in the README.

Other ways to help

  • Report a bug or an idea in Issues.
  • Report a security problem privately, as the Security page explains.
  • Tell another developer who runs Claude Code.

Will it stay free?

The app for one person stays free. A paid plan may come later for teams and companies (shared budgets, central keys, audit, support). The code is under the Functional Source License: anyone may read, audit, build and use it, except to sell a competing product, and each version becomes Apache 2.0 two years after its release.
