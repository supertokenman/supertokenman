---
title: Memory
summary: Facts and decisions about a project that Claude can read, kept in versions.
slug: memory
---
**Memory** (from `Cmd K`) holds facts and decisions about the current project: which package manager
it uses, how tests run, what was decided and why.

- Each item records who wrote it: you, Claude, or a session.
- Editing an item keeps the old version. Nothing is overwritten.
- Only things about the project: files, packages, commands, decisions. Never notes about people.
