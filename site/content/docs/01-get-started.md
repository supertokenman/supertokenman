---
title: Get started
summary: Install the app, open a project and run your first panel.
---
1. [Download](/download/) the build for your Mac and drag SuperTokenMan into Applications.
2. Open it. A panel is one Claude Code session in one folder: pick the folder of your project.
3. Type what you want in the box at the bottom and press Enter. `Cmd Enter` runs the line in the shell instead.

Claude Code runs with your Claude account or an Anthropic API key. Usage is billed by Anthropic on your
account.

## Find anything

`Cmd K` opens the command palette. Every sheet in these docs (Budgets, Spend, Memory, Playbooks,
Connections, Appearance) is one search away.
