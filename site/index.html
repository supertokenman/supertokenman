nº 2 · what it does

six things your agents do together.

Pictures from the demo, with sample data. Tap a card to turn it.

Agents

Many panels. One task.

Run Claude Code in parallel panels, each in its own git worktree, so two tasks never write over each other.

Group panels under a task with one budget and one timeline. Close it with the decision: merged, dropped, or what was learned.

  • Worktrees per panel
  • Playbooks with checkpoints
  • Routines that draft while you work
Control

Ask first. Then run.

Tool calls wait for your approval, unless you let a persona run the safe ones alone. Isolate a panel in a Docker container with only its folder and no network, or trim the tools it can reach.

The cost of each turn sits above the chat. Budgets per project, persona and task are checked before each turn starts.

  • Approvals per tool call
  • Isolation without network
  • Budgets checked before each turn
Memory

Remembered. Never overwritten.

Facts and decisions about each project, kept in versions, with who wrote them: you, Claude, or a session.

Answers built from your documents show their sources, and say which claims the sources support.

  • Versioned project memory
  • Sources and citations
  • Documents into memory
