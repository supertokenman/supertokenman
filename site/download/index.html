SuperTokenMan for Mac.

Signed with a Developer ID and notarized by Apple, so macOS opens it without warnings.

Download for Apple silicon Download for Intel

Not sure which? Apple menu, About This Mac: a chip named Apple M is Apple silicon; a processor named Intel is Intel.

Install

  1. Open the downloaded .dmg.
  2. Drag SuperTokenMan into Applications.
  3. Open it from Applications and start a panel. Claude Code runs with your Claude account or an Anthropic API key.

What you need

  • MacApple silicon or Intel.
  • ClaudeA Claude plan or an Anthropic API key. Usage is billed by Anthropic on your account, not by us.
  • OptionalDocker, to isolate panels. Git, for worktrees and changes.

Check the download

Each release lists a SHA256SUMS file. Download it next to the .dmg and run:

cd ~/Downloads
shasum -a 256 -c SHA256SUMS --ignore-missing

A line ending in OK means the file is the one we published. To check the signature and the notarization:

spctl -a -vv /Applications/SuperTokenMan.app

It should say accepted and source=Notarized Developer ID.

Updates

The app checks the releases on GitHub at launch and every 6 hours. When there is a new version it shows what changed and installs only when you say so. Turn the check off in Appearance, Check for updates automatically.

Older versions

Every version, with its notes and checksums, is on GitHub Releases.
